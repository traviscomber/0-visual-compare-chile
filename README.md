# Videntia

> **Industrial Property Intelligence OS**

[Videntia](https://videntia.app) is a decision-intelligence operating system for industrial property. It connects trademarks, patents, technology intelligence, monitoring, cases, governance and decision support in one traceable workflow.

This repository began as Visual Compare Chile and evolved into the broader Videntia product.

<p align="center"><strong>Research → Signal → Case → Governance → Decision</strong></p>

---

## Three intelligence verticals

| Vertical | Purpose |
|---|---|
| **Trademarks** | Similarity, availability, monitoring, conflicts and case intelligence |
| **Patents** | Patent research, technical evidence, monitoring and decision support |
| **Technologies** | Technology landscape, R&D signals, competitive intelligence and emerging opportunities |

These verticals share the same evidence, case and governance layer rather than behaving like isolated search tools.

---

## Operating model

```text
PUBLIC / OFFICIAL SOURCES
          │
          ▼
 Research + monitoring
          │
          ▼
       Signal
          │
          ▼
        Case
          │
          ▼
 Evidence + analysis
          │
          ▼
 Review / governance
          │
          ▼
 Decision brief + action
```

The system preserves the distinction between source evidence, deterministic business rules and AI-assisted interpretation.

---

## Product principles

1. **Evidence remains attributable.** Source, date and provenance stay visible.
2. **AI does not close cases autonomously.** Consequential decisions remain governed by authorized users.
3. **Deterministic rules stay deterministic.** Authorization, readiness and workflow gates are not delegated to a model.
4. **Monitoring creates actionable signals.** The system should connect a detected change to a case or decision path.
5. **Industrial property is continuous intelligence.** Registration is one event inside a longer research, monitoring and governance lifecycle.

---

## Architecture

Videntia is implemented with Next.js/React/TypeScript, PostgreSQL/Supabase and server-side integrations for official/open data and AI-assisted analysis.

The application separates:

- canonical industrial-property evidence;
- role and tenant authorization;
- deterministic workflow/governance logic;
- AI-generated explanations and structured intelligence.

Real deployment credentials and privileged tokens are never part of public repository documentation.
